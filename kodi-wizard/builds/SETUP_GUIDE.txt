================================================================================
STEP 1: AUTHORIZE TRAKT (OPTIONAL - Recommended)
================================================================================

Trakt keeps track of what you watch across devices.

For Each Addon (The Crew, The Loop, Umbrella):

1. Open the addon (e.g., The Crew)
2. Go to: Settings → Accounts → Trakt
3. Click "Authorize Trakt"
4. You'll see a code like: ABC-123-DEF
5. On your phone/computer:
   - Visit: https://trakt.tv/activate
   - Enter the code shown on screen
   - Click "Continue"
6. Return to Kodi - it will say "Authorized!"

Repeat for each addon you want to use.

Time: 2 minutes per addon

================================================================================
STEP 2: ADD REAL-DEBRID (HIGHLY RECOMMENDED)
================================================================================

Real-Debrid gives you:
✓ 1080p and 4K quality streams
✓ Zero buffering
✓ Instant playback
✓ 50+ links per movie/show

Cost: ~$3.50/month (worth every penny!)

Setup:

1. Get Real-Debrid account:
   - Visit: https://real-debrid.com/
   - Sign up (takes 2 minutes)
   - Subscribe to premium (~$3.50/month)

2. Get your API token:
   - Go to: https://real-debrid.com/apitoken
   - Copy the long code shown

3. Add to each addon:

   The Crew:
   - Open The Crew
   - Settings → Accounts → Real-Debrid
   - Paste API token
   - Test connection ✓

   The Loop:
   - Open The Loop
   - Settings → Accounts → Real-Debrid
   - Paste API token
   - Test connection ✓

   Umbrella:
   - Open Umbrella
   - Settings → Accounts → Debrid Services → Real-Debrid
   - Paste API token
   - Test connection ✓

Time: 5 minutes total (one-time setup)

STEP 3: START STREAMING!
================================================================================

You're ready! Here's how to use your addons:

THE CREW (Best for Movies & TV Shows):

1. Open The Crew from Kodi home screen
2. Go to Movies → Trending (or TV Shows)
3. Select something to watch
4. Wait 10-20 seconds (it's finding links)
5. Links will appear (with Real-Debrid you'll see 50+)
6. Select a link (1080p RD recommended)
7. Enjoy! 🍿

THE LOOP (Best for Live Sports):

1. Open The Loop
2. Select sport (Football, Basketball, etc.)
3. Find your event
4. Select stream
5. Watch live! 🏈

UMBRELLA (Alternative to The Crew):

1. Open Umbrella
2. Movies or TV Shows

5. Enjoy! 📺

================================================================================
TROUBLESHOOTING
================================================================================

No Links Found:
  → Make sure Real-Debrid is configured
  → Check your internet connection
  → Try a different movie/show

Buffering:
  → Use Real-Debrid (eliminates 99% of buffering)
  → Select lower quality link (720p instead of 1080p)
  → Check internet speed (need 15+ Mbps for 1080p)

Addon Won't Open:
  → Settings → Add-ons → My Add-ons → Video Add-ons
  → Select addon → Enable

Crashes:
  → Settings → System → Advanced → Clear Cache
  → Restart Kodi
